# 비즈니스 애널리틱스 2026 (Business Analytics)

부경대학교 시스템경영공학부 학부 4학년 · BALAB

**강의 게시판: https://balab-pknu.github.io/bizanalytics/**

게시판에서 주차별 주제와 노트북·과제를 Google Colab으로 바로 연다. 과목 구성·일정·평가는
게시판의 **과목 안내** 탭에 있다.

실제 산업 데이터를 분석해 의사결정 권고안을 만드는 과목이다. 매주 교재는 같은 순서로
전개된다 — 데이터의 출처와 수집 경위를 확인하고 탐색한 뒤, 그 데이터로 풀 문제를 세우고,
문제를 풀 산업공학 이론(통계적 검정, 회귀분석, 군집, 분류, 수요예측, 재고관리, 품질관리,
최적화, 인과추론)을 수식으로 복습한 다음, 분석해 권고로 끝맺는다.

## 구성

| 폴더 | 내용 |
|---|---|
| `notebooks/` | 주차별 **교재** 노트북 — 데이터와 탐색 → 문제 → 이론 → 분석·권고. 결정에 직결되는 코드는 비어 있고 수업 중 함께 채운다 |
| `labs/` | **랩** — 강의와 다른 실데이터에 그 주 기법을 적용한다. `# LAB-TODO` 빈칸을 채우면 마지막 셀이 완료를 확인한다 |
| `theory/` | **배경이론 문서** — 교재 4절이 요약만 싣고 가리키는 전문(정의·수식·유도). 게시판의 **이론** 버튼으로 연다 |
| `balab.py` | 데이터 로더 — 노트북 첫 셀이 자동으로 불러온다 |

데이터는 [bizanalytics-data](https://github.com/BALAB-PKNU/bizanalytics-data) 미러에서
첫 셀 실행 시 자동으로 내려받는다. 로컬 설치나 계정 가입은 필요 없다.

## 사용법

1. 게시판(또는 이 저장소)에서 노트북을 Colab으로 연다.
2. 첫 셀을 실행하면 데이터와 공용 코드가 준비된다.
3. 수정·제출하려면 "파일 → Drive에 사본 저장" 뒤 사본에서 작업한다.
