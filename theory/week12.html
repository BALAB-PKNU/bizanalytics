도입: 네트워크 분석이란

  • 네트워크 분석(network analysis): 대상 사이의 연결 관계를 이용하여, 연결망에서 중요한 대상과 서로 밀접하게 연결된 그룹을 찾는 방법
  • 네트워크 분석 적용분야
    • 항공·물류: 노선 연결망에서 많은 경로가 지나는 거점을 찾아, 거점이 멈출 때 쓸 우회 노선을 마련함
    • 공급망: 거래 연결망에서 대체 경로가 없는 거래처를 찾아 공급처를 늘림
    • 조직 관리: 이메일·협업 연결망에서 부서 사이를 잇는 사람을 찾아 정보 전달 경로와 인력 배치를 정함
    • 마케팅: 고객 사이의 추천 연결망에서 많은 고객과 이어진 고객을 찾아 홍보 대상을 정함

도입: 네트워크 데이터의 특징과 표현

  • 네트워크 데이터(network data): 대상과 대상 사이의 관계를 기록한 데이터
    • node: 네트워크를 이루는 대상, 예: 사람, 회사, 공항
    • link(arc, edge): 두 node를 잇는 관계, 예: 친구 관계, 거래, 항공 노선
  • 회귀·분류 데이터와의 차이
    • 회귀·분류 데이터: 한 행이 대상 하나, 열은 그 대상의 속성
    • 네트워크 데이터: 한 행이 두 대상 사이의 관계 하나
  • link의 방향과 가중치
    • 방향이 있는 link: A → B와 B → A를 구별함, 예: 이메일, 송금
    • 방향이 없는 link: A → B와 B → A를 구별하지 않음, 예: 친구 관계
    • 가중치가 있는 link: 관계의 횟수나 크기를 기록함, 예: 운항 편수, 거래액
    • 가중치가 없는 link: 관계가 있는지 없는지만 기록함

도입: 경로와 거리

  • 경로(path): 서로 다른 두 node 사이를 link를 따라 도달하는 방법, 지나는 node를 차례로 나열해 나타냄
  • 경로의 길이: 경로에 들어 있는 link의 수
  • 최단 경로(shortest path): 두 node를 잇는 경로 중 길이가 가장 짧은 경로, 여러 개일 수 있음
  • 거리(distance) d(u,v): 두 node u, v 사이 최단 경로의 길이, 두 node를 잇는 경로가 없으면 ∞

예: Medici와 Strozzi를 잇는 경로 중 셋

도입: 네트워크 분석의 방법과 지표

  • 네트워크 분석의 목적
    • 개별 node의 네트워크 안에서의 중요도를 다양한 지표를 통해 평가
    • 서로 밀접한 연관이 있는 community를 그룹핑하여 발견
  • node의 중요도 지표
    • centrality: 얼마나 중요한 위치를 차지하는가
      • degree centrality: 얼마나 많은 node와 직접 이어져 있는가
      • betweenness centrality: 다른 node들 사이를 얼마나 많이 잇고 있는가
    • robustness: 그 node가 빠지면 네트워크에서 떨어져 나가는 node가 몇 개인가
  • community detection
    • modularity: 그룹 안쪽이 그룹 사이보다 얼마나 촘촘하게 이어져 있는가
    • greedy modularity algorithm: modularity가 커지도록 그룹을 차례로 합쳐 community를 찾는 방법

centrality: betweenness centrality

  • 정의: betweenness centrality는 다른 두 node 사이의 최단 경로가 node i를 얼마나 지나는지 나타내는 값
    bi=∑s<t,s,t≠iσst(i)σst
    • σst: node s와 t를 잇는 최단 경로의 개수
    • σst(i): 그중 i를 지나는 최단 경로의 개수
  • 의미: bi가 클수록 i는 다른 node들 사이를 이어 주는 위치에 있어 중요하다고 봄

robustness

  • 정의: ri는 node i를 뺀 뒤 가장 큰 connected component에 속하지 못한 node, 즉 떨어져 나간 node의 개수
    ri=(n−1)−|Cmax|
    • connected component: 서로 연결된 node들로 이루어진 부분 네트워크
    • |Cmax|: 가장 큰 connected component의 node 수
  • 의미: ri가 클수록 i가 빠질 때 네트워크가 많이 끊어지므로, i는 네트워크를 이어 주는 중요한 node이고 네트워크의 robustness는 i에 크게 달려 있다고 봄

community: modularity

  • 정의: modularity Q는 그룹 안 link의 비율이 무작위 네트워크에서 기대되는 비율보다 얼마나 높은지 나타내는 값
    Q=∑c[Lcm−(dc2m)2]
    • Lc/m: 그룹 c 안 link의 실제 비율, Lc는 그룹 c 안의 link 수, m은 전체 link 수
    • (dc/2m)2: 무작위 네트워크에서 그룹 c 안 link의 기대 비율, dc는 그룹 c에 속한 node의 degree 합
  • 무작위 네트워크: link m개를 만들 때마다 양쪽 node를 각각 degree에 비례하는 확률 ki/2m로 뽑아 이은 네트워크
    • 예: Medici는 degree 6이므로 6/40=0.15의 확률로 뽑힘
    • 한쪽 node가 그룹 c에서 뽑힐 확률은 그룹 c에 속한 node의 확률을 더한 dc/2m, 양쪽 모두 그룹 c에서 뽑힐 확률은 (dc/2m)2
  • 예: 그룹 1의 실제 비율 6/20=0.3, 기대 비율 (16/40)2=0.16, 차 0.14
  • 의미: Q가 클수록 그룹 안에 link가 무작위 네트워크보다 많이 모이게 나눈 것

community: greedy modularity algorithm

  • 정의: greedy modularity algorithm은 Q가 가장 크게 늘어나는 두 그룹을 하나씩 합쳐 가며 Q가 큰 나눔을 찾는 방법
    ΔQ=LABm−2·dAdB(2m)2
    • ΔQ: 두 그룹 A, B를 합칠 때 Q가 늘어나는 양, LAB: A와 B 사이 link 수, dA,dB: 두 그룹 각각에 속한 node마다 이어진 link 수(degree)를 더한 값

절차

  1. node마다 그룹 하나로 시작함: 그룹 15개, Q=−0.08375
  2. link로 이어진 두 그룹의 모든 쌍에 대해 ΔQ를 구함
  3. ΔQ가 가장 큰 두 그룹을 하나로 합침
  4. 가장 큰 ΔQ가 0 이하가 될 때까지 2~3을 되풀이함

계산 예: 첫 합치기, Pazzi와 Salviati

Pazzi의 degree 1, Salviati의 degree 2, 둘 사이 link 1개

ΔQ=120−2·1·21600=0.0475

link로 이어진 다른 어느 두 그룹보다 ΔQ가 커서 가장 먼저 합쳐짐

해석 시 주의: centrality 순위와 제거 효과의 차이

  • 주의: betweenness centrality는 최단 경로만 세므로, betweenness centrality가 높은 node를 빼도 더 긴 경로가 남아 있으면 네트워크가 끊어지지 않음
  • 예: Guadagni는 betweenness centrality 2위이지만, 빼도 떨어져 나가는 가문은 Lamberteschi 하나뿐임
  • 대응: 끊어지는 정도는 centrality 순위로 짐작하지 않고, node를 직접 빼서 ri로 계산함
