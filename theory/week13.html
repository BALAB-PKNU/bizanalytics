도입: 네트워크 분석이란

  • 네트워크 분석(network analysis): 대상 사이의 연결 관계를 이용하여, 연결망에서 중요한 대상과 서로 밀접하게 연결된 그룹을 찾는 방법
  • 네트워크 분석 적용분야
    • 항공·물류: 노선 연결망에서 많은 경로가 지나는 거점을 찾아, 거점이 멈출 때 쓸 우회 노선을 마련함
    • 공급망: 거래 연결망에서 대체 경로가 없는 거래처를 찾아 공급처를 늘림
    • 조직 관리: 이메일·협업 연결망에서 부서 사이를 잇는 사람을 찾아 정보 전달 경로와 인력 배치를 정함
    • 마케팅: 고객 사이의 추천 연결망에서 많은 고객과 이어진 고객을 찾아 홍보 대상을 정함

도입: 네트워크 데이터의 특징과 표현

  • 네트워크 데이터(network data): 대상과 대상 사이의 관계를 기록한 데이터
    • node: 네트워크를 이루는 대상, 예: 사람, 회사, 공항
    • link(arc, edge): 두 node를 잇는 관계, 예: 친구 관계, 거래, 항공 노선
  • 회귀·분류 데이터와의 차이
    • 회귀·분류 데이터: 한 행이 대상 하나, 열은 그 대상의 속성
    • 네트워크 데이터: 한 행이 두 대상 사이의 관계 하나
  • link의 방향과 가중치
    • 방향이 있는 link: A → B와 B → A를 구별함, 예: 이메일, 송금
    • 방향이 없는 link: A → B와 B → A를 구별하지 않음, 예: 친구 관계
    • 가중치가 있는 link: 관계의 횟수나 크기를 기록함, 예: 운항 편수, 거래액
    • 가중치가 없는 link: 관계가 있는지 없는지만 기록함

도입: 경로와 거리

  • 경로(path): 서로 다른 두 node 사이를 link를 따라 도달하는 방법, 지나는 node를 차례로 나열해 나타냄
  • 경로의 길이: 경로에 들어 있는 link의 수
  • 최단 경로(shortest path): 두 node를 잇는 경로 중 길이가 가장 짧은 경로, 여러 개일 수 있음
  • 거리(distance) d(u,v): 두 node u, v 사이 최단 경로의 길이, 두 node를 잇는 경로가 없으면 ∞

예: Medici와 Strozzi를 잇는 경로 중 셋

경로길이
Medici – Ridolfi – Strozzi2
Medici – Barbadori – Castellani – Strozzi3
Medici – Tornabuoni – Guadagni – Bischeri – Strozzi4

주황: 최단 경로, 파랑 점선: 더 긴 경로

d(Medici,Strozzi)=2

도입: 네트워크 분석의 방법과 지표

  • 네트워크 분석의 목적
    • 개별 node의 네트워크 안에서의 중요도를 다양한 지표를 통해 평가
    • 서로 밀접한 연관이 있는 community를 그룹핑하여 발견
  • node의 중요도 지표
    • centrality: 얼마나 중요한 위치를 차지하는가
      • degree centrality: 얼마나 많은 node와 직접 이어져 있는가
      • betweenness centrality: 다른 node들 사이를 얼마나 많이 잇고 있는가
    • robustness: 그 node가 빠지면 네트워크에서 떨어져 나가는 node가 몇 개인가
  • community detection
    • modularity: 그룹 안쪽이 그룹 사이보다 얼마나 촘촘하게 이어져 있는가

centrality: degree centrality

  • 정의: degree centrality는 node i의 degree ki, 즉 i에 직접 이어진 link의 수
    ki=∑jaij
    • aij: i와 j 사이에 link가 있으면 1, 없으면 0
  • 의미: 이웃이 많은 node일수록 다른 node와 직접 주고받는 관계가 많아 중요한 위치에 있다고 봄

Medici는 15개 가문 가운데 가장 많은 6개 가문과 혼인으로 직접 이어져 있었음. 재산 1위 Strozzi는 4개

8 / 17

centrality: betweenness centrality

  • 정의: betweenness centrality는 다른 두 node 사이의 최단 경로가 node i를 얼마나 지나는지 나타내는 값
    bi=∑s<t,s,t≠iσst(i)σst
    • σst: node s와 t를 잇는 최단 경로의 개수
    • σst(i): 그중 i를 지나는 최단 경로의 개수
  • 의미: bi가 클수록 i는 다른 node들 사이를 이어 주는 위치에 있어 중요하다고 봄

A·B·C 그룹과 D·E·F 그룹을 오가는 최단 경로는 모두 X를 지남

X는 link가 2개뿐이지만 betweenness centrality가 가장 큼

계산 예: X

A·B·C에서 하나, D·E·F에서 하나를 고른 3×3=9쌍은 최단 경로가 하나뿐이고 모두 X를 지나므로 쌍마다 비율이 1

bX=9×1=9

robustness

  • 정의: robustness는 node가 빠져도 네트워크가 연결을 유지하는 정도. node i가 빠질 때의 영향 ri는 i를 뺀 뒤 남은 n−1개 node 가운데 가장 큰 connected component에 들지 못한 node의 수
    ri=(n−1)−|Cmax|
    • connected component: 서로 연결된 node들로 이루어진 부분 네트워크
    • |Cmax|: 가장 큰 connected component의 node 수
  • 의미: ri가 클수록 i가 빠질 때 네트워크가 많이 끊어지므로, i는 네트워크를 이어 주는 중요한 node이고 네트워크의 robustness는 i에 크게 달려 있다고 봄

X를 빼면 E·F는 나머지 node와 이어지지 않아 떨어져 나감

가장 큰 connected component는 A·B·C·D

rX=(7−1)−4=2

rMedici=(15−1)−11=3

12 / 17

community

  • 정의: community는 서로 촘촘하게 이어진 node의 그룹. 그룹 안에는 link가 많고, 그룹 사이에는 link가 적음
  • 의미: degree·betweenness·robustness가 node 하나의 위치를 본다면, community는 네트워크가 어떤 그룹으로 나뉘는지 봄. 같은 그룹의 node들은 서로 밀접하게 연관되어 있다고 봄

A·B·C, D·E·F, G·H·I 안에는 link가 촘촘함

그룹 사이 link는 C–D와 F–G 두 개뿐

community 3개: A·B·C, D·E·F, G·H·I

community: modularity

  • 정의: 그룹 c의 modularity qc는 그룹 c 안 link의 실제 비율이 link를 아무렇게나 이었을 때 기대되는 비율보다 얼마나 높은지 나타내는 값
    qc=Lcm−(dc2m)2
    • Lc/m: 그룹 c 안 link의 실제 비율 (Lc: 그룹 c 안의 link 수, m: 전체 link 수)
    • (dc/2m)2: link를 아무렇게나 이었을 때 그룹 c 안에 들어올 것으로 기대되는 비율 (dc: 그룹 c에 속한 node의 degree 합)
  • 의미: qc가 클수록 그룹 c 안쪽이 그룹 사이보다 촘촘하게 이어진 그룹이라고 봄

계산 예: 그룹마다 qc

cLcdcqc
A·B·C373/10 − (7/20)² = 0.1775
D·E·F383/10 − (8/20)² = 0.14
G·H·I252/10 − (5/20)² = 0.1375

A·B·C의 qc가 가장 커서 가장 촘촘하게 뭉친 그룹
