시계열 예측이란

  • 시계열 예측(time series forecasting): 시간 순서로 관측한 과거의 값을 이용하여, 아직 관측하지 않은 미래의 값을 예측하는 방법
  • 시계열 예측 적용분야
    • 재고관리: 다음 몇 달의 수요를 예측하여 생산량과 발주량을 정함
    • 교통: 승객 수를 예측하여 열차·항공 편성, 좌석 공급, 인력 배치를 정함
    • 마케팅: 매출을 예측하여 예산과 자금 계획을 세움
    • 전력: 전력 사용량을 예측하여 설비 용량을 계획함

도입

시계열 예측의 수학적 정의

  • 시계열: 시점 t=1,2,…,n에서 차례로 관측한 값의 수열 y1,y2,…,yn
  • 시계열 예측: 마지막 관측 시점 n까지의 값으로 h기간 뒤의 값 yn+h를 추정하는 함수 f를 정하는 문제
    y^n+h=f(y1,y2,…,yn),h=1,2,…,H
    • y^n+h: 시점 n까지 관측한 값으로 낸 h기간 뒤의 예측값
    • h: 예측 기간(horizon), H: 예측할 가장 먼 기간
  • 회귀분석과의 차이
    • 회귀분석: 같은 행에 주어진 설명 변수 x로 y를 설명함
    • 시계열 예측: 같은 수열의 과거 값으로 아직 관측하지 않은 미래 값을 냄
  • 예: 6년치 분기 매출 24개(n=24)로 다음 해 네 분기 y^25,…,y^28를 예측함(H=4)

구성 요소와 계절 주기

  • 대부분의 시계열에서는 추세(trend)와 계절성(seasonality)을 발견할 수 있음
    • 추세: 오랜 기간에 걸쳐 값이 꾸준히 늘거나 줄어드는 움직임
    • 계절성: 일정한 기간마다 같은 모양이 되풀이되는 움직임
  • 백화점 매출 그래프에서 확인할 수 있는 추세와 계절성

도입

시계열 예측 모델링 방식

  • 시계열 예측 방법은 예측값을 계산하는 함수 f를 정하는 방식에 따라 나눌 수 있음
  • Naive 예측
    • 모형을 추정하지 않고, 과거에 관측한 값을 그대로 미래의 예측값으로 쓰는 방식
    • naive 예측은 마지막 관측값을, seasonal naive 예측은 직전 주기의 같은 계절에 관측한 값을 예측값으로 씀
  • 자기회귀(autoregression)
    • 같은 시계열의 직전 몇 기간의 값을 설명 변수로, 그 기간의 값을 결과 변수로 두는 회귀 모형
    • 추정한 회귀식에 가장 최근의 관측값을 넣어 다음 기간의 예측값을 계산함
    • 설명 변수 X가 직전 p개 기간의 y값인 회귀 모형: yt=f(yt−1,yt−2,…,yt−p)
  • 추세·계절성 회귀
    • 시계열의 값을 시간의 함수로 보는 회귀 모형
    • 각 기간의 값을 그 기간이 언제인지, 즉 시간이 얼마나 흘렀는지(추세)와 어느 계절인지(계절성)로 설명함
    • 설명 변수 X가 시점 t와 계절인 회귀 모형: yt=f(t, 계절)

평가

학습 기간과 테스트 기간

  • 예측 방법이 좋은지는 아직 관측하지 않은 미래의 값을 얼마나 잘 맞히는지로 판단해야 함
  • 하지만 미래의 값은 아직 없으므로, 가지고 있는 자료의 마지막 기간을 미래처럼 떼어 두고 평가함
    • 학습 기간(training): 앞부분의 자료, 모형을 추정하는 데 씀
    • 테스트 기간(test): 마지막 부분의 자료, 학습 기간으로 만든 예측값과 실제 값을 비교하는 데 씀
  • 자료는 무작위로 나누지 않고, 연·분기 같은 적절한 시간 단위로 끊어 시간 순서대로 나눔(temporal split)

평가

예측 오차와 평가 지표

  • 예측 오차: 테스트 기간 각 시점의 실제 값에서 예측값을 뺀 값 et=yt−y^t
  • 테스트 기간 전체의 오차를 하나의 숫자로 요약하여 방법끼리 비교함
    • MSE: 1m∑et2, m은 테스트 기간의 길이
    • MAPE: 100m∑|etyt|, 오차를 실제 값 대비 %로 나타내어 단위가 다른 자료끼리도 비교할 수 있음
  • 예: seasonal naive 예측의 6년차 오차 4.4, 4.9, 5.5, 11.1로 계산하면 MSE 49.21, MAPE 8.17%

평가

학습 오차와 테스트 오차

  • 학습 오차(training error): 모형을 추정한 학습 기간에서 실제 값과 적합값으로 계산한 오차
  • 테스트 오차(test error): 추정에 쓰지 않은 테스트 기간에서 실제 값과 예측값으로 계산한 오차
  • 학습 오차는 모형이 이미 본 자료로 계산하므로 작게 나오기 쉬움. 따라서 방법은 테스트 오차로 비교함

평가

테스트 오차로 방법 선택

  • 테스트 오차가 가장 작은 방법을 고름
  • 예시에서는 계절 자기회귀의 테스트 MAPE가 3.39%로 가장 작음

17 / 19

평가

예측 기간(forecast horizon)이 길어지면

  • 예측 기간(forecast horizon): 마지막 관측 시점에서 몇 기간 뒤까지 예측하는지를 나타내는 길이 h
  • 예측 기간이 길어질수록 예측 오차가 커짐
    • 자기회귀는 두 기간 이상 앞을 예측할 때 앞 기간의 예측값을 다시 입력으로 쓰므로 오차가 쌓임
    • 추세·계절성 회귀는 추정한 추세가 앞으로도 그대로 이어진다고 가정하므로, 멀리 갈수록 실제 값과 벌어질 수 있음
  • 테스트 기간에서 비슷하게 맞힌 방법들도 그보다 먼 미래에서는 예측이 크게 달라질 수 있음
